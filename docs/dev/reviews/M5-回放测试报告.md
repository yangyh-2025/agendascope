### 1. 首轮 FAIL 根因（次日归并 0%、跨语言 0%、事件大量漏报）

诊断方法：单案例（xinjiang-cotton-2021）带探针重放 + 全案例逐案解剖，共定位 4 个根因，
前 3 个为代码缺陷，第 4 个为估算参数失准：

1. **引擎活跃窗口与回放历史时间轴脱钩（主根因，(a)+(b) 类缺陷）**。
   `nearest_active_topic` 与 `nextday_merge` 的 `_find_merge_target` 用墙钟
   `datetime.now(UTC)` 计算活跃议题窗口（`last_seen_at >= now-30d`），回放案例文章
   为 2018-2023 历史时间戳，全部议题落在窗口外。单案例探针证据：9/9 篇文章
   outcome=new_micro；3 轮 nextday_merge 候选 4/8/9 个、merged=0；引擎视角
   最近议题全部 None；同一时间轴视角下同事件质心相似度实测 0.71-0.94。
   修复：活跃窗口时间基准可注入（`now` 参数贯穿 online/repository/merge），
   回放注入模拟时间（assign 用文章发布时间、日界归并用新日 00:00Z）；
   回放改为每案例独立事务评估后回滚（案例隔离，防跨案例时间轴重叠污染）。
2. **次日归并候选集 C 漏 forming（实现偏离算法 3）**。算法 3 的 C 为
   「昨日至今的新议题/微簇集」，实现曾窄化为 `lifecycle_state='nascent'`——
   同事件 forming 子簇（在线归簇已获同伴）永不归并。逐案解剖证据：时间轴修复后
   8 个误拆案例全部残留 forming↔forming 同事件对，质心相似度 0.65-0.89
   （eu-ai-act 0.889 / fukushima 0.851 / neg-crawled 0.832 / mahsa-amini 0.805 /
   russia-ukraine 0.760 / navalny 0.690 / aukus 0.654）。
   修复：候选集扩为 (nascent, forming)，并加方向保护
   （target.first_seen_at <= candidate.first_seen_at，更老 topic_id 存续）。
3. **单遍评估顺序伪影**。russia-ukraine 案例 a2 同轮先评估 sim=0.608<0.62 未并，
   同轮主簇随后合并 4 篇、质心漂移后 sim 升至 0.6285，但单遍已结束无下一轮可追。
   修复：nextday_merge 单轮内迭代至不动点（每轮归并后以更新质心重评剩余候选）。
4. **通讯社锚点倾斜 6h 失准（估算参数）**。时间轴修复后首发国准确率一度跌至
   70.8%：beirut/meng-wanzhou/fukushima/nordstream/suez/turkey/who-covid 七案例
   通讯社晚到 1-3h，却凭 6h 倾斜反超真正更早的本地首发（如 LB L'Orient Today
   15:10 vs AP 17:10、TR Hurriyet 01:20 vs AP 02:20）。该问题在首轮被根因 1
   掩盖（单篇议题首发判定恒正确）。
